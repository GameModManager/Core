# Feature Map - MO2 vs GMM (moved)

This file used to hold a second, older copy of the feature map. It is a strict
ancestor of [`docs/featuremap.md`](../docs/featuremap.md) and was kept alive
long enough to be mistaken for the real thing.

It has been retired. Two copies of a document that gets read as evidence is
worse than one: the older copy still claimed `UsvfsLibrary`, `UsvfsConnector` and
`build_usvfs_mapping` as implemented, and none of those symbols exists anywhere
in the repository. Every ticket drafted from it had to be corrected against the
source before it could be implemented.

**The live document is [`docs/featuremap.md`](../docs/featuremap.md).** It
carries the per-row verification markers (`✔` / `·` / `[win]`) and the dated
verification note that this copy never had.

Retired 2026-09-29.
